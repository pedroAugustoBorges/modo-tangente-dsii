# Modo Tangente

## Sobre o projeto

O Modo Tangente é um tutor conversacional para apoiar os estudos da disciplina Desenvolvimento de Servidores II. A proposta é ajudar os alunos a revisar Java, programação orientada a objetos, Reflection, Servlets, Spring, desenvolvimento web com Spring Boot e JPA. Pelo chat, o estudante poderá tirar dúvidas e retomar conversas. As respostas serão geradas por um modelo de linguagem via OpenRouter, com apoio de materiais da disciplina e em um tom descontraído inspirado no jeito de explicar e no humor do professor Felipe Cannarrozo Lourenço.
